# Smoke-check и скриншоты

Протокол итоговой проверки по разделу «Контролируемый smoke-check» из [spec.md](../spec.md). По spec.md результат существует только после фактического наблюдения, а не по ответу ИИ. Поэтому колонку «Факт» заполняет студент.

## Подготовка

1. Остановите сервер, если он запущен, и удалите `boris.db`, чтобы начать с чистого состояния.
2. Запустите `npm start` и откройте `http://localhost:3100` в основном браузере (браузер А).
3. **Сразу**, до шага 2 протокола, откройте ту же страницу во втором браузере (браузер Б), например в Safari, если А — Chrome. Не обновляйте Б до шага 3: только на «устаревшей» странице можно попытаться занять уже занятый слот.
