### 1. Каркас Node.js-проекта
- **Сделано:**
  - `package.json` со скриптом `npm start`, без внешних зависимостей;
  - `server.js` на встроенном `node:http`: слушает `127.0.0.1`, порт 3100 по умолчанию (меняется через `PORT`), отдаёт `public/index.html` на `/`, на остальные пути — 404;
  - при занятом порте сервер завершается с понятной ошибкой;
  - `public/index.html` — заглушка без данных;
  - `.gitignore`: `node_modules`, файлы базы `*.db*`, `.DS_Store`.
- **Драйвер SQLite:** встроенный модуль `node:sqlite`. Проверено: в Node.js v24.18.0 работает без флагов и предупреждений, SQLite 3.53.1. Внешний драйвер не нужен.
- **Порт:** 3100 вместо 3000. На машине разработки порт 3000 занят другим локальным проектом. На macOS сервер мог занять тот же порт без ошибки и перехватить `localhost` у чужого проекта.
- **Проверка (2026-10-17, факт):**
  - `npm install` — без ошибок, 0 уязвимостей;
  - `npm start` — «Сервер запущен: http://localhost:3100»;
  - `GET /` — 200, `text/html; charset=utf-8`, заголовок «Кто выгуливает Бориса»;
  - `GET /nope` — 404 «Не найдено»;
  - второй запуск на занятом 3100 — «Порт 3100 уже занят…», код выхода 1;
  - страница открылась во встроенном браузере.
- **Статус:** готово.
